D3 projection setup (from 06-UI-SPEC.md):
```typescript
const projection = geoNaturalEarth1()
  .scale(160)
  .translate([width / 2, height / 2])
  .rotate([-10, 0])

// SVG dimensions
const width = 800
const height = 450
// viewBox: "0 0 800 450"

// Project lat/lng to SVG [x, y]:
function projectPoint(lat: number, lng: number): [number, number] | null {
  const projected = projection([lng, lat])  // d3-geo takes [lng, lat]
  return projected ? [projected[0], projected[1]] : null
}
```

Arc quadratic Bézier path formula (from 06-UI-SPEC.md):
```
midX = (startX + endX) / 2
midY = (startY + endY) / 2
curvature = Math.sqrt((endX - startX)^2 + (endY - startY)^2) * 0.3
controlX = midX
controlY = midY - curvature  // curves upward

SVG path: `M ${startX},${startY} Q ${controlX},${controlY} ${endX},${endY}`
```

Grid lines (from 06-UI-SPEC.md):
- Latitude lines at SVG y values for 60°N, 30°N, 0° (equator), 30°S, 60°S — project via projection([0, lat])
  Equator: stroke="rgba(229,166,99,0.10)" strokeWidth="1" strokeDasharray="6 10"
  Others: stroke="rgba(255,255,255,0.04)" strokeWidth="0.5"
- Longitude lines every 30° from -180 to 150: project start [lng, 85] and end [lng, -85]
  stroke="rgba(255,255,255,0.03)" strokeWidth="0.5"
