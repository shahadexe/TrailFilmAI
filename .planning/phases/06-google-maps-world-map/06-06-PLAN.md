  <name>Task 2: Google Cloud Console setup — enable API and restrict key (D-13, D-14)</name>
  <what-built>
    Plans 01–05 have migrated the codebase to @vis.gl/react-google-maps. The build is clean.
    A NEXT_PUBLIC_GOOGLE_MAPS_API_KEY env var is needed for the map to render in development and production.
  </what-built>
  <steps>
    Complete these steps in Google Cloud Console before proceeding:

    STEP 1 — Get or create a Google Maps API key:
    1. Go to https://console.cloud.google.com/
    2. Select your project (or create a new one named "Trailfilm")
    3. Navigate to: APIs & Services → Credentials
    4. Click "Create Credentials" → "API key"
    5. Copy the generated API key

    STEP 2 — Enable Maps JavaScript API (D-14):
    1. Navigate to: APIs & Services → Library
    2. Search for "Maps JavaScript API"
    3. Click the result → click "Enable"
    4. Confirm: the API appears in "Enabled APIs & services"

    STEP 3 — Restrict the API key (D-13):
    1. In Credentials, click your API key name to open its settings
    2. Under "Application restrictions", select "HTTP referrers (web sites)"
    3. Add these two referrer patterns:
       https://trailfilm.vercel.app/*
       http://localhost:3000/*
    4. Under "API restrictions", select "Restrict key" and choose "Maps JavaScript API"
    5. Click Save
    6. Wait ~5 minutes for restrictions to propagate

    STEP 4 — Add to your local .env.local:
    Open .env.local in your project and add:
      NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=YOUR_KEY_HERE
    (Do not commit .env.local — it is in .gitignore)

    STEP 5 — Test locally:
    Run: pnpm dev
    Navigate to a trip with a generated story (one with GPS coordinates)
    Open the cinematic viewer — the Google Maps dark map should render
    Verify: dark tile layer visible, amber markers on chapter locations, dashed amber path connecting them
    Also visit the landing page — scroll to the world map section to verify arcs animate on scroll
  </steps>
