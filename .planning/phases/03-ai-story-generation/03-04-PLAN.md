<objective>
Extend `/trip/[id]` (Phase 2 RSC page) to render Phase 3's three story-section states (draft / generating / completed) below the existing photo grid, plus build the four supporting components:

- **StorySection** — wraps the chapter list with the "YOUR STORY" eyebrow + amber-hairline gradient divider (UI-SPEC §"YOUR STORY Section Divider").

Output: 1 modified RSC page + 4 new client components. No regeneration UI in this plan (Plan 03-05). No new API routes.
